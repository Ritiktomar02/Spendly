# Coding Style

- Use JavaScript with ES Modules.
- Prefer simple, readable code over clever solutions.
- Use `camelCase` for variables and functions.
- Use `PascalCase` for React components and classes.
- Keep functions focused and reasonably small.
- Avoid unnecessary abstractions and utility layers.
- Reuse existing code before creating new helpers.
- Add comments only when the logic is not obvious.
- Do not add dependencies unless they are actually needed.

### General Rule

Prefer the simplest implementation that correctly solves the requested task.
