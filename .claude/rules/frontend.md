# Frontend Rules

- Use React + Vite.
- Use Tailwind CSS v3.
- Keep pages in `src/pages/`.
- Keep reusable components in `src/components/`.
- Put API communication in `src/services/`.
- Use native `fetch()` for API calls.
- Keep UI components simple and reusable.
- Preserve the existing Spendly design.
- Do not change colors, spacing, typography, or layout unless required.
- Keep existing routes working.
- Do not introduce another CSS framework.

### React

- Use functional components.
- Use React hooks where needed.
- Avoid unnecessary global state.
- Keep component responsibilities clear.
